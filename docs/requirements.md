# 要件定義（requirements.md）— テンプレート

このドキュメントは **「何を作るか」** をまとめるものです。
新しいアプリを始めるときは、`{{ }}` を埋めて自分のプロジェクト用に書き換えてください。
（「どう作るか」は [`architecture.md`](architecture.md) に書きます。）

---

## 1. このアプリの目的
iPhone等で撮った写真の傾き（水平）を補正すると、回転の分だけ四隅が欠けてクロップされ、元のピクセル数より小さくなってしまう。今までは仕方なくペイントで無理やり元のピクセル数まで引き伸ばしていたが、縦横比が歪む問題があった。さらにPaintは色空間（Display P3）やHDR情報（ゲインマップ）を正しく扱えないため、編集前後で明るさ・色の見え方まで変わってしまう問題もあった。このアプリは、画像ビューア機能に加えて、傾き補正やクロップで小さくなった画像を、歪ませず・色や明るさも変えずに、自然な形で元のサイズ相当まで復元できる画像編集アプリ。

## 2. 使う人（想定ユーザー）
- 開発者自身（iPhone 15 Pro・iPhone 17で撮った写真を日常的に編集している）
- 利用シーン：自分のPC（Windows / Mac）で、撮った写真の傾きを直したり、簡単な編集をする時

## 3. 対象プラットフォーム
- [x] Mac / [x] Windows / [ ] Linux / [ ] iOS / [ ] Android
- 最初からWindows・Macの両対応を目指す（Tauriのためコードはほぼ共通化できる見込み）

## 4. 機能一覧
「まず作る（MVP）」と「あとで」に分けて書く。全部を最初に作ろうとしない。

### MVP（最初のリリースに必要な最小限）
| ID | 機能 | 説明 |
|---|---|---|
| F1 | 画像ビューア | フォルダ内の写真を一覧・サムネイル表示し、拡大して閲覧できる |
| F2 | 傾き補正（水平補正） | 画像を回転させて水平を直す。はみ出た四隅は縦横比を保ったままクロップする |
| F3 | 解像度の自動復元（AIアップスケール） | 傾き補正・クロップで画像が小さくなった時、下記「段階リスト」の中で直近上の段階まで、AIアップスケール（waifu2x系エンジン、写真用モデル）で自然に復元する。ダウンスケールはしない、常に上の段階に合わせる |
| F4 | ドラッグ&ドロップの一括編集 | 複数ファイルをドラッグ&ドロップして、傾き補正などをまとめて適用できる（UI仕様は詳細検討中） |
| F5 | 手動クロップ | 任意の範囲を切り取る。F3と同じロジックで、直近上の段階までAIアップスケールする |
| F6 | 色空間・HDR情報の保持 | 画像の読み込み・編集・保存を通して、ICCプロファイル（Display P3等の色空間情報）とHDRゲインマップを維持する。編集前後で明るさ・色の見え方が変わらないようにする |

#### 解像度の段階リスト（F3・F5で使用）
| 段階 | 解像度 | 画素数 |
|---|---|---|
| 1 | 8064×6048 | 48MP |
| 2 | 5712×4284 | 24MP |
| 3 | 4032×3024 | 12MP |
| 4 | 3264×2448 | 8MP |

※ 段階は写真ごとに実測して判定する（固定端末リストに依存しない）。アップスケール量は常に1段階分以内に収まるよう設計し、AI補完による不自然さを抑える。

### あとで（フェーズ2以降）
| ID | 機能 | 説明 |
|---|---|---|
| F10 | 汎用AIアップスケール | 古い・小さい写真を任意の倍率で綺麗に拡大する独立機能 |
| F11 | 明るさ・コントラスト等の簡単補正 | |

## 5. 画面一覧
| 画面 | 役割 |
|---|---|
| ビューア（ホーム） | フォルダを開いて写真を一覧・サムネイル表示。クリックで拡大表示 |
| 編集画面 | 選択した写真を開いて、傾き補正・クロップ・解像度復元(AIアップスケール)を行う |

---

## 6. データ（ざっくり）
- このアプリはDBを持たず、**画像ファイルそのもの**を直接読み書きする（フォルダ・ファイルベース）
- 編集操作の履歴やUndoなど、アプリ内部の一時的な状態のみメモリ上で保持する

---

## 7. やらないこと（スコープ外）
- クラウド同期・複数端末間の共有は当面やらない
- レイヤー編集・高度な合成など、Photoshopのような本格的な編集機能は当面やらない
- フィルター・エフェクト（色調変更以外の加工）は当面やらない
- 汎用AIアップスケール（フェーズ2の任意倍率拡大）はMVPには含めない（F3・F5の段階復元のみ）
