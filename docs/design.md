# デザインシステム（design.md）

UIの見た目のルール集。色・文字・余白などを**トークン（名前つきの値）**で定義し、全画面で統一する。
実体のCSS変数は [`src/index.css`](../src/index.css)、視覚見本は [`styleguide.html`](styleguide.html)。
**色を変えるときは、この3つを一緒に更新する。**

---

## 1. 原則

1. **土台はニュートラル、主張はブランド色**：画面の大半は**ほんのりプラム（紫）寄り**のニュートラルで落ち着かせ、ブルー・グラデ・ゴールドは要所だけ。無彩色ではなくブランドに微かに色を寄せることで、世界観に馴染ませる。
2. **主役はブルー `#54A1E8`**：ボタン・リンク・選択状態に使う。3色グラデ（青→紫→桃）はロゴ・見出し・特別な場面のみ。
3. **意味のある増減だけ色を付ける**：増加・成功＝緑／減少・エラー＝赤。普段の数字や文字は中立色にする。
4. **色は状態のためだけに使う**：赤緑は「増減・成否」に予約し、通常の分類は位置やラベルで区別する。
5. **ライト／ダーク両対応**：どちらも同じ品質で読めること（単純反転はしない）。
6. **アクセシビリティ**：本文と背景のコントラストを確保。フォーカスは必ず可視化。

> ブランド色は**トークンなので差し替え可能**。アプリごとに `--accent` とグラデを変えれば、UI全体の印象を一括で調整できる。

## 3. 使い方ルール

- **数値**：`--pos`/`--neg` は「増加・減少」「前月比」など**増減の意味を持つ数字だけ**に。通常の数値は `--text`。
- **分類**：色分けに頼らない。列の位置・見出し・ラベルで区別する。
- **グラデ**：多用しない。ロゴ、主要見出し、主要CTAボタン、グラフの1本など「主役の主役」だけ。
- **フォーカス**：キーボード操作時、`--focus` の輪郭を必ず表示（`:focus-visible`）。
- **状態の可視化**：数字だけでなく、チップ／色帯でも状態が分かるように（色覚に依存しすぎない）。
- **テーマ切替**：文字ラベルを付けず、☀️/🌙 のアイコンボタンにする（ヘッダー右）。
- **リンク**：`--link` を使う。ダークは主役ブルーより明るい青にして視認性を確保する。

## 4. タイポグラフィ

数字を多く扱うUIを想定。フォントは端末標準（外部読込なし）、桁の揃う数字は**等幅そろえ**を使う。

| 用途 | トークン | 値 |
|---|---|---|
| 標準フォント | `--font-sans` | `system-ui, -apple-system, "Hiragino Sans", "Noto Sans JP", sans-serif` |
| 数字・コード | `--font-mono` | `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` |

**サイズ段階**：`--text-xs 12` / `--text-sm 13` / `--text-base 14` / `--text-md 15` / `--text-lg 18` / `--text-xl 22` / `--text-2xl 28`（px）。
**ウェイト**：本文 400、強調・見出し 600、数字の強調 500。
**数字の桁揃え**：金額表示に `font-variant-numeric: tabular-nums;` を使う。

---

## 5. レイアウト（余白・角丸・影）

**余白（4px基準）**：`--space-1 4` / `-2 8` / `-3 12` / `-4 16` / `-5 20` / `-6 24` / `-8 32` / `-10 40` / `-12 48`（px）。
**角丸**：`--radius-sm 6` / `-md 10` / `-lg 14` / `-xl 18` / `-pill 999`（px）。
**影**（控えめ・テーマで調整）：`--shadow-sm`（カード）/ `--shadow-md`（浮いた面）。ダークは影より枠線で階層を表す。

---

## 6. 実装

- CSS変数は `src/index.css` の `:root` に定義（ライトを既定）。
- ダークは `@media (prefers-color-scheme: dark)` ＋ `:root[data-theme="dark"]` / `[data-theme="light"]` で上書き（OS設定と手動切替の両対応）。
- コンポーネントは**必ずトークン経由**で色を参照する（生のhexを直書きしない）。

---

## 7. 更新運用
色やトークンを変えたら、**`docs/design.md`（本書）・`src/index.css`・`docs/styleguide.html` の3つを必ず一緒に更新**する。ズレると全画面に波及するため。
