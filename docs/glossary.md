# 用語集（glossary.md）— 学習用

このテンプレートで出てくる用語を、やさしくまとめた学習用リファレンス。
新しい用語が出たら、ここに追記していく。

---

## UI・デザイン

| 用語 | 意味 |
|---|---|
| アプリシェル（app shell） | サイドバー＋メイン領域など、アプリ全体の骨組みレイアウト。 |
| サイドナビ／ナビゲーションレール | 画面左のナビ。折りたたむとアイコンだけの細い「レール」になる。 |
| メインコンテンツ領域／コンテンツペイン | サイドバーの右側、実際の中身が表示される主役の領域。 |
| FAB（フローティングアクションボタン） | 画面に浮かぶ丸い操作ボタン。「新規作成」などに使う（スマホ由来）。 |
| デザイントークン | 色・文字サイズ・余白などに名前を付けた「値の定義」。全画面で使い回す。 |
| セマンティックトークン | 「背景」「主役」「危険」など"役割"で色を定義したトークン。 |
| プライマリ／アクセント | UIの主役の色（ボタン・リンク等）。このテンプレートはブルー。 |
| 情報設計（IA / Information Architecture） | 「何をどこに置くか」の整理。ナビの分け方などの土台。 |
| キーラインシェイプ／アイコングリッド | アイコンを、方眼と円で"計算して"作るための下敷き。 |
| ハブ&スポーク型／サイドバー型 | 画面遷移の型。前者は中心に戻る、後者は常時ナビで直接移動。 |
| prefers-color-scheme | OSのライト/ダーク設定を検知するCSSの仕組み。 |
| CSS変数（カスタムプロパティ） | `--accent` のように値を変数化する仕組み。トークンの実体。 |

## 開発・技術

| 用語 | 意味 |
|---|---|
| ウォーキングスケルトン（歩く骨格） | 画面→処理→DBを最小限つないだ"動く土台"。最初に通す。 |
| source of truth（正本） | データの正本。どこを唯一の正しいデータとするかを決めておく。 |
| マルチマスター問題 | 複数端末で同じデータを編集し、後で衝突して解決が大変になる問題。 |
| マイグレーション | DBのテーブル構成を、バージョン管理しながら更新する仕組み。 |
| Tauri | 1つのコードでMac/Win/モバイル向けアプリを作る枠組み。 |
| Rust | 高速・堅牢なプログラミング言語。中核ロジック担当。 |
| TypeScript | 型のあるJavaScript。UI担当。書いた瞬間に間違いを検知しやすい。 |
| React / Vite | UIを作るライブラリ / 高速なビルドツール。 |
| SQLite / SQLCipher | 1ファイルで完結するDB / それを暗号化する拡張。 |
| ホットリロード | 開発中、ファイルを保存すると再起動なしで画面へ即反映される仕組み。 |

## Git・GitHub

| 用語 | 意味 |
|---|---|
| リポジトリ | プロジェクトの変更履歴を管理する入れ物。 |
| ブランチ | 作業を枝分かれさせる仕組み。mainを汚さず開発する。 |
| コミット | 変更を1つの記録として確定すること。 |
| PR（プルリクエスト） | 「このブランチをmainに取り込んで」の申請＆レビューの場。 |
| マージ | ブランチの変更をmainに合流させること。 |
| .gitignore | Gitに上げないファイルを指定する設定。 |

## フロントエンドのUI部品（初心者向け）

| 用語 | 意味 |
|---|---|
| モーダル／ダイアログ | 画面中央に重ねて出す小窓。確認や入力に使う。 |
| オーバーレイ／バックドロップ | モーダルの背後を暗くする膜。 |
| ポップオーバー | 要素の近くにふきだし状で出る小さなパネル。 |
| ドロップダウン | クリックで下に開く選択メニュー。 |
| ツールチップ | ホバーすると出る短い説明。 |
| トースト／スナックバー | 画面端に一時的に出る通知。 |
| バッジ／チップ | 小さなラベル（状態やタグ）。 |
| タブ | 画面内で内容を切り替える見出し。 |
| アコーディオン | クリックで開閉して中身を出す折りたたみ。 |
| パンくずリスト | 現在地を示す階層リンク（例：ホーム > 一覧）。 |
| ページネーション | ページ送りのUI。 |
| スケルトン／スピナー | 読み込み中の仮表示／くるくる回るやつ。 |
| アバター | ユーザーの丸いアイコン。 |
| FAB | 画面に浮かぶ丸い作成ボタン。 |
| ケバブ／ミートボール／ハンバーガー | 縦三点／横三点／三本線の「メニューを開く」アイコン。 |
| プライマリ／セカンダリ／ゴースト／アイコンボタン | 主役／脇役／枠だけ／アイコンだけ、のボタン種別。 |
| トグルスイッチ／チェックボックス／ラジオボタン | on-offや選択の入力部品。 |
| 入力フィールド／プレースホルダ／ラベル | フォームの入力欄／薄い例示文字／項目名。 |
| 空状態（Empty State） | データがまだ無いときの案内画面。 |
| ドロワー | サイドからスライドして出る引き出し式のパネル（モバイルのメニュー等）。 |
| スクリム／暗幕 | ドロワーやモーダルの背後を暗くする半透明の膜。外側タップで閉じる合図にもなる。 |

## レイアウト・状態の用語

| 用語 | 意味 |
|---|---|
| ビューポート | 画面の表示領域。 |
| レスポンシブ | 画面幅に応じてレイアウトが変わる設計。 |
| Flexbox／Grid | 要素を横並び／格子状に並べるCSSの仕組み。 |
| padding／margin／gap | 内側の余白／外側の余白／要素どうしの隙間。 |
| z-index | 要素の重なり順（大きいほど手前）。 |
| ホバー／アクティブ／フォーカス／無効(disabled) | マウス乗せ中／選択中／キーボード選択中／押せない、の状態。 |
| スティッキー／固定(fixed) | スクロールしても位置が固定される配置。 |
| ブレークポイント | レスポンシブでレイアウトを切り替える画面幅の境目（例：640px・1024px）。 |
